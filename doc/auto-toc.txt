*auto-toc.txt*        Automatic Markdown and MDX tables of contents

                                                             *auto-toc*
auto-toc.nvim keeps a linked table of contents in .md and .mdx files.
It requires Neovim 0.12+ and the bundled Markdown Tree-sitter parsers.

BEHAVIOR                                               *auto-toc-behavior*

The plugin starts enabled for each normal .md and .mdx buffer. It records
headings on open and writes a TOC after a heading changes. Updates run after
150 ms of inactivity or before writing the buffer. Update operations edit the
buffer and become part of the file when you save it.

The TOC goes before the document body, after any leading front matter. It
lists Markdown headings written with one to six # characters. Code blocks are
excluded. The links use GitHub-style fragments. A skipped heading level adds
indentation up to the limit for a Markdown list item. Setext headings count
toward duplicate fragment numbering.
MDX support covers Markdown headings outside JSX and JavaScript. MDX renderers
need to generate matching heading IDs for the links to work.

The plugin owns the lines between its start and end marker comments. It
updates that region in place and removes it when the last heading disappears.
If the document contains unmatched, reversed, or duplicate markers, fix the
markers before refreshing the TOC.

COMMANDS                                               *auto-toc-commands*

:AutoTocOn                                                     *:AutoTocOn*
    Enable automatic generation for the current buffer and refresh its TOC.

:AutoTocOff                                                   *:AutoTocOff*
    Disable automatic generation for the current buffer. The existing TOC
    stays in the document.

The setting applies for the lifetime of the buffer.
